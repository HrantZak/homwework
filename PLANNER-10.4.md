# Мой план — версия 10.4 (37)

Открыть: Сегодня → Мой план.

1. Следующее дело: ближайший день сдачи, затем важность и оценка времени. Время задаётся пользователем, не выдаётся за измеренное.
2. Шаги: открыть задание → Разбить на шаги. Добавление, отметка, удаление шагов, шаблон, важность и время. Сохранение на устройстве.
3. Завтра: уроки с учётом замены дня, активные задания до конца завтрашнего дня, включая просроченные; список вещей с предложениями и отметками отдельно для каждой даты.
4. Учебные карточки: чат → плюс → Расписание или Задания. Получатель выбирает «Посмотреть и принять». Показываются текущая и предложенная версии расписания. Замена только после принятия; прежнее расписание остаётся в корзине. Задания добавляются без перезаписи существующих UUID. Повторное принятие того же сообщения блокируется.
5. Сохранение: локальные задания работают без интернета; статус и ручное сохранение в «Мой план». Очередь сообщений сохраняется отдельно для аккаунта и собеседника. Повтор идёт при восстановлении сети в открытом чате или при следующем открытии чата; есть ручная кнопка. Это не фоновая доставка при закрытом приложении. Первый анонимный вход требует интернета. Стабильный ID и проверка документа на сервере защищают от дубликата при потерянном подтверждении. Локальное хранение не заменяет облачную резервную копию.
6. Корзина: задания при удалении, расписание перед заменой и удалением урока. Восстановление расписания требует подтверждения и сохраняет текущую версию. Удаление навсегда отдельно подтверждается. Автоматического срока очистки нет.
7. Цели: десятибалльная шкала, все записанные оценки предмета, сохранённые веса, число и вес будущих оценок. Показывается требуемый средний балл или недостижимость. Итоговая оценка преподавателя может рассчитываться иначе.

## Проверки

В Tests/main.swift добавлены проверки ранжирования задач, завершённых задач, взвешенного расчёта, недостижимой цели, корректного расписания, повторных UUID, неправильного времени и сохранения шагов/корзины.

На Windows компилятор SwiftUI отсутствует: эти тесты и сборка ещё не запускались. Запустить GitHub Actions → Validate design после отправки файлов. Затем Build Uspevai IPA для установки.

На двух iPhone проверить дополнительно:

- Чат с выключенной сетью → отправка нескольких текстов/карточек → закрытие приложения → повторное открытие чата → включение сети. Каждый элемент должен появиться на втором телефоне ровно один раз.
- Запрет Firebase: очередь остаётся; после исправления правил ручной повтор отправляет её.
- Отмена импорта не меняет данные; принятие и восстановление не меняют оценки.
- Удаление задания, перезапуск и восстановление сохраняют его шаги.
- Пустое расписание, переход месяца и дни перевода часов, крупный текст, тёмная тема, отключённые анимации.

Новые карточки заданий используют уже разрешённый тип text с JSON-полезной нагрузкой; новых разрешений Firebase не добавлено. Если прежние правила чатов ещё не опубликованы, их всё равно нужно опубликовать.
