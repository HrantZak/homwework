# Успевай

Текущая версия: **10.1.0 (34)** — новый профиль с кольцами статистики, коллекция стилей и обновлённый маркет.

Приложение для iPhone: расписание, разовые замены учебных дней, домашние задания, импорт фото, оценки, профиль, учебный огонёк и 130 достижений четырёх уровней редкости.

## Запуск

1. На Mac установите Xcode и XcodeGen (`brew install xcodegen`).
2. Выполните `xcodegen generate` и откройте `Uspevai.xcodeproj`.
3. В Signing & Capabilities выберите свою Apple Developer Team и уникальный Bundle Identifier.
4. Подключите iPhone и нажмите Run.

## IPA через GitHub

Добавьте Secrets: `APPLE_CERTIFICATE_BASE64`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_PROVISION_PROFILE_BASE64`, `KEYCHAIN_PASSWORD`. Создайте тег вида `v6.1.0` или запустите workflow вручную. Готовый IPA появится в Artifacts. Обычный push в `main` не запускает дорогую macOS-сборку — это бережёт бесплатные минуты GitHub Actions.

На Windows содержимое файлов для Secrets можно получить в PowerShell:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\path\certificate.p12")) | Set-Clipboard
[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\path\profile.mobileprovision")) | Set-Clipboard
```

Первая команда копирует сертификат, вторая — provisioning profile. В Secret нужно вставлять результат команды целиком, без кавычек и имени файла.

Каждый новый релиз должен получать новые `MARKETING_VERSION` и `CURRENT_PROJECT_VERSION` в `project.yml`. Номер меняется в настройках проекта до сборки, поэтому Xcode не пытается перезаписывать `Info.plist` во время работы.

## Сторонние материалы

Шрифт Monocraft создан IdreesInc, распространяется по SIL Open Font License 1.1 и не связан с Mojang или Minecraft. Полный текст лицензии находится в `Uspevai/Fonts/OFL.txt`.

Без Apple Secrets Action создаёт `Uspevai-unsigned.ipa`. Такой IPA необходимо подписать своим Apple ID через AltStore или Sideloadly. При наличии Apple Secrets дополнительно создаётся подписанный `Uspevai.ipa`.

## Дизайн и производительность в 10.1

- Профиль: обложка с орбитами, крупный аватар, четыре круговых показателя, прогресс уровня, фильтр полученных наград и редактирование с отменой.
- Маркет: каталог и коллекция, поиск, категории с плавным переходом, сортировка по цене, фильтр по балансу, статичные миниатюры и живой предпросмотр одного предмета.
- Покупка: закреплённая кнопка, стоимость и остаток баланса, защита от повторной покупки, бесплатное применение и снятие стиля. Владение и расходы сохраняются одной записью; старые покупки загружаются из прежнего формата.
- Центр ученика: кольца статистики и сегментная диаграмма оценок; прогноз цели учитывает вес оценок.
- Статистика пересчитывается при изменении учебных данных. Каталог индексирован по категории и идентификатору, коллекция — по множеству идентификаторов.
- Общие карточки используют непрозрачный фон и облегчённые тени. Вращение рамок работает только на видимом активном экране; отключается при энергосбережении и уменьшении движения. Анимации показателей и появления конечные.
- Перед уходом в фон отложенные записи сохраняются. Таймер учитывает время в фоне, но сессия не восстанавливается после завершения процесса.

Учебная серия учитывает последовательные дни оценок, посещений и дат создания выполненных заданий. Точная дата завершения старых заданий не хранится. Экономика монет по-прежнему основана на текущих учебных данных: удаление оценки или снятие готовности задания может уменьшить баланс.

### Проверка на Mac

Workflow **Validate design** доступен вручную: проверяет расчёты и собирает приложение для симулятора без подписи. Локально расчёты проверяются так:

```sh
swiftc Uspevai/Models.swift Uspevai/StudySnapshot.swift Tests/main.swift -o /tmp/uspevai-checks
/tmp/uspevai-checks
```

Перед выпуском проверь светлую и тёмную темы, крупный текст и VoiceOver; фильтры пустой коллекции; покупку при недостаточном и точном балансе; повторное применение и снятие; перезапуск после покупки; уход с экрана и энергосбережение при вращении рамки. Для измерения FPS, памяти и энергопотребления нужен iPhone и Instruments — численные улучшения пока не измерялись.
