# Успевай 10.3 — спокойный ритм

Визуальное направление: глубокий индиго для главных карточек, светлые чистые поверхности, мятный акцент прогресса. Системные шрифты и пользовательские шрифты магазина сохранены. Рекомендации UI/UX Pro Max адаптированы к SwiftUI; веб-шрифты и внешние ресурсы не добавлялись.

## Изменения

- Сегодня: адаптивная главная карточка с кольцом прогресса, быстрые действия «Записать» и «Сфокусироваться», доступ к настройкам.
- Расписание: выбор дня недели, возврат к сегодняшнему дню, подписанные для VoiceOver стрелки.
- Задания: свободно растущая карточка прогресса, пустое состояние внутри списка вместо перекрывающего интерфейс слоя.
- Общие поверхности и фон: меньше градиентных слоёв, без теней у каждой обычной карточки; отдельные цвета для тёмной темы.
- Профиль: устранён повтор пустой витрины, убрана анимация появления каждой ячейки достижений.
- Движение: короткие переходы, настройка «Плавные анимации», системное уменьшение движения имеет приоритет. Удалена искусственная заставка запуска.

## Проверка перед выпуском

На Windows выполнена проверка diff; компиляция SwiftUI и визуальная проверка здесь недоступны. GitHub Actions → Validate design выполняет проверку моделей и сборку для симулятора. Этот workflow ещё нужно запустить после отправки изменений.

На iPhone проверить:

1. Все пять вкладок в светлой и тёмной теме, включая выбранный шрифт магазина.
2. Максимальный размер текста, длинные названия уроков, экран маленького iPhone и горизонтальную ориентацию.
3. Расписание: переход воскресенье/понедельник, граница месяца, «Сегодня», замена дня.
4. Задания: пустой список, пустой фильтр, создание, выполнение и удаление.
5. Настройки анимации: выключение, перезапуск, включение системного уменьшения движения.
6. Маркет и 100+ достижений: быстрая прокрутка, открытие предпросмотра и возврат. Измерить кадры на устройстве; обещание фиксированной частоты кадров без измерений не даётся.
7. Таймер фокуса: пауза, сброс, возврат из фона. Сессия этого экрана локальная и заканчивается при закрытии листа.

Данные и правила Firebase в этой версии не изменялись. Для установки изменений нужна новая сборка IPA.
