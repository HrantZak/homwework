# Проверка друзей и сообщений — 10.2.0 (35)

## Обязательная настройка

1. Firebase Console → проект Uspevai → Firestore → Rules.
2. Заменить текст полным содержимым `firestore.rules` из этого проекта и нажать Publish.
3. В Authentication → Sign-in method должен быть включён Anonymous.
4. Собрать новую IPA через Build Uspevai IPA и обновить приложение у обоих участников.

Правила в репозитории не публикуются автоматически при сборке IPA.

## Проверить на двух телефонах

- Оба участника публикуют профиль в Профиль → Сообщество → Профиль.
- Первый вводит код второго в «Друзья», нажимает «Добавить», затем кнопку сообщения.
- Отправить текст в обе стороны. Галочка означает подтверждение сервером, а не прочтение другом.
- На втором телефоне диалог появляется в «Чаты», даже если первый участник ещё не добавлен.
- Внутри входящего диалога нажать «Добавить». Удаление друга не удаляет чат.
- При отказе доступа сообщение остаётся в поле; после исправления правил повторить подключение и отправку.
- При отключённом интернете возможен статус ожидания сервера; не удалять и не переустанавливать приложение, пока отправка ожидается.
- Отправить расписание, оценки и аналитику через «+» с подтверждением.

Друзья и черновики хранятся локально. При смене анонимного аккаунта старый доступ к переписке автоматически не восстанавливается. Push-уведомления и подтверждения прочтения не реализованы.

## Автоматическая проверка правил

В `Tests/firebase`: `npm ci`, затем `npm test` (Node 22 и Java 21).
Тесты работают только с локальным demo-проектом эмулятора, не с настоящими сообщениями.
Они проверяют отправку в обе стороны, входящие диалоги, миграцию порядка участников и отказ постороннему.

Проверено 5 сентября 2026: все 4 группы тестов прошли в локальном эмуляторе, включая учебные вложения. iOS-сборка и обмен на реальных телефонах в этой среде не проверены.

Подписки с метаданными и их отключение: https://firebase.google.com/docs/firestore/query-data/listen
